Privacy Policy

Last updated: 30 September 2026

The "Encoder" application is a personal tool operated by the owner of the Encoder YouTube channel. It uses the YouTube Data API and the YouTube Analytics API with read-only scopes to retrieve the statistics, analytics and comments of the owner's own channel.

Data

The application reads channel and video statistics of the account that signs in. Retrieved data is stored only on the owner's own computer and used to produce private reports about the channel. No data is shared with, sold to, or transferred to third parties. No data about other users is collected. The application does not write, modify or delete anything on YouTube.

Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by the owner at any time.
